# CachyOS · niri · Noctalia — переносимый набор

Снимок рабочего стола от **14 ноября 2026**: niri 26.04 (CachyOS, с blur),
Noctalia **5.4.1** — нативная версия с TOML/Luau, не старый QML/Quickshell.
Старые репозитории не изменены.

## Что внутри

- niri: анимации, прозрачность/blur, скругления, раскладка `us,ru` и хоткеи.
- Noctalia: бар, dock, стеклянные панели, тема, медиаплеер и визуализатор.
- **Все 9 используемых плагинов**, а не весь каталог: собственные `equalizer`,
  `ruh-vpn`, `timer`; `wallhaven`, `notes`, `mpvpaper`, `screen_recorder`,
  `keybind-cheatsheet`, `cursor`.
- Локальные изменения recorder: быстрый индикатор начала записи и открытие
  последней записи правой кнопкой. Используется твой стандартный видеоплеер.
- Скриншоты с уникальным именем файла в буфере; нумерация записей.
- Текущие обои и необязательный чёрно-белый конфиг Alacritty.

**Не перенесены:** ключи/токены, VPN-серверы и подписки, история/заметки/буфер,
GitHub auth, браузерные профили, настройки сети, драйверы, Waydroid, личные
программы и `.desktop`-ярлыки, настройки конкретных аудиоустройств.

## Установка

У тебя должны быть установленный CachyOS и **обычный пользователь**. Установщик
не ставит пакеты, не включает службы и не меняет твои программы по умолчанию.
Сначала проверь наличие нужных пакетов в своих репозиториях:

```bash
sudo pacman -S --needed niri noctalia python wl-clipboard xdg-utils xdg-user-dirs slurp
```

Для звука/X11-приложений/порталов, если их ещё нет:

```bash
sudo pacman -S --needed pipewire pipewire-pulse wireplumber xwayland-satellite \
  xdg-desktop-portal xdg-desktop-portal-gnome xdg-desktop-portal-gtk
```

Поставь **свой** терминал, браузер и файловый менеджер. Затем лучше из другой
сессии или TTY: niri сразу перечитывает изменённый конфиг.

```bash
git clone https://github.com/Romalakino/cachyos-niri-share.git
cd cachyos-niri-share
python3 install.py --dry-run   # только показать файлы; ничего не менять
python3 install.py             # установить с резервными копиями
# Необязательно: добавить ещё и настройки Alacritty
# python3 install.py --alacritty
```

После установки выйди из текущей сессии и выбери **niri** на экране входа.
Не запускай установщик с `sudo`.

## Что отличается от моего компьютера

- Нет жёстких `DP-2`, разрешения и 240 Гц — niri сам выбирает поддерживаемый режим.
  Для своей частоты/масштаба: `niri msg outputs`, затем `~/.config/niri/cfg/display.kdl`.
- Пути автоматически подставляются под твой `$HOME` и XDG-каталоги Фото/Видео.
- Терминал выбирается из установленных. Браузер и файлы открываются через `xdg-open`.
  Для явного выбора раскомментируй строки в `~/.config/niri/apps.conf`:
  `TERMINAL=kitty`, `BROWSER=firefox`, `FILE_MANAGER=dolphin` — только имя программы,
  без аргументов. Этот файл — shell-конфиг, не вставляй туда чужой код.
- Плагины лежат в `~/.local/share/noctalia/dotfiles-plugins` и работают без скачивания
  при каждом старте; снимок перекрывает официальные копии. Автообновление выключено.
- VPN **выключен**, данных подключений нет. Запись по умолчанию H.264 / 60 fps,
  а не настройки моей видеокарты и 120 fps.
- Alacritty, fish, системные службы и настройки остальных программ не перезаписываются
  по умолчанию. Шаблон Noctalia меняет цвета только niri.

## Необязательные функции

| Функция | Что поставить / сделать |
|---|---|
| Эквалайзер | `easyeffects lsp-plugins` — оба нужны; пресеты генерирует `eqctl` |
| Запись экрана | `gpu-screen-recorder slurp`; возможности кодирования зависят от GPU |
| Видеообои | `mpvpaper`; своё видео выбрать в настройках плагина |
| Курсор как у меня | `capitaine-cursors` или сменить тему в `cfg/misc.kdl` |
| VPN | `sing-box`, Python-зависимости из `noctalia-plugins/ruh-vpn/pyproject.toml`; см. README плагина |

Установщик включает recorder / EQ / mpvpaper только при наличии соответствующих
программ. Если поставил их позже, включи плагины через настройки Noctalia
(чтобы не запускать установку заново поверх своих правок).
VPN включается вручную: `noctalia msg plugins enable vlad-dev/ruh-vpn`,
серверы добавляй **свои**. Локальные proxy-службы из старого набора не нужны.

Старого файла видеообоев `Samurai-Autumn-1080p60.mp4` на компьютере уже нет,
поэтому отсутствующий файл не добавлен в автозапуск. Статичные обои есть в `assets/`.
Виджеты рабочего стола назначаются первому доступному монитору; при необходимости
поправь расположение в настройках Noctalia → Desktop → редактор.

## Основные клавиши

`Mod` = Super/Win. Caps Lock переключает `us` ↔ `ru`.

| Клавиша | Действие |
|---|---|
| Mod+Enter / T | Терминал |
| Mod+W / B | Браузер |
| Mod+E / N | Файлы |
| Mod+Space | Меню приложений |
| Mod+S | Control Center |
| Mod+Ctrl+S | Настройки Noctalia |
| Mod+Shift+Enter | Обои |
| Mod+Shift+E / V | Эквалайзер / VPN (если включены) |
| Print / Mod+Shift+S | Скриншот области как файл в буфере |
| Mod+Print | Скриншот как обычное изображение в буфере |
| Mod+Alt+L | Блокировка |
| Mod+Q / F / O | Закрыть окно / fullscreen / обзор |
| Mod+1…9 | Рабочие столы |
| Mod+Shift+Escape | Полная шпаргалка клавиш |

## Бэкапы и проверки

Каждый заменяемый файл получает соседний `<имя>.backup-<дата-время>`.
Повторная установка создаёт новый бэкап, не теряет старый и не создаёт `niri/niri`.
Остальные файлы в твоих каталогах остаются на месте. Для отката скопируй нужные
backup-файлы обратно под исходными именами; перед перезапуском проверь конфиг.

```bash
niri validate
noctalia config validate
python3 -m unittest -v test_install.py
```

Если `niri validate` ругается на `blur`/`background-effect`, твоя сборка niri
не поддерживает расширения из CachyOS. Установщик остановится до копирования.
На другом ПК не проверены драйверы, аппаратная запись и фактическая работа плагинов.
